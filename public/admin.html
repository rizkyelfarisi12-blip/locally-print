Riwayat cetak

Semua pekerjaan cetak dari semua komputer. Pengguna biasa tidak melihat daftar ini.

Lokasi program pendukung

Kosongkan kolom = dicari otomatis. Pengaturan di sini diprioritaskan di atas file .env dan langsung berlaku tanpa restart. Isi path lengkap ke file .exe (di File Explorer: klik kanan file > Copy as path).

Umum

Keamanan

PIN cetak diminta dari semua pengguna. Tanpa PIN admin, halaman ini hanya bisa dibuka dari komputer server.

Port dan ALLOW_PREFIX diatur di file .env, lalu jalankan restart.bat.
